# BeatSlide：ウェブ公開キット

自分のURLでウェブ公開して、スマホの「ホーム画面に追加」で、アプリのように使えるようにするための一式です。サーバーは要りません。費用は、無料です。

## 中身
- `index.html` … アプリ本体（ホーム画面に追加、バックアップの書き出し／読み込み、チップの確認画面つき）
- `manifest.webmanifest`, `sw.js`, `icon-*.png` … ホーム画面に追加とオフライン対応のためのファイル
- `config.js` … 連絡先、制定日、チップのURLを書く場所（ここだけ書き換えます）
- `privacy.html` … プライバシーポリシー（5言語）。`config.js` の内容が自動で入ります

## 公開の手順（GitHub Pages・無料）
パソコンのブラウザだけで、できます。コマンドは使いません。

1. github.com でアカウントを作ります（メールアドレスで登録）。
2. 右上の「＋」→「New repository」。Repository name は、`beatslide` など好きな名前にして、**Public**を選び、「Create repository」を押します。
3. 作ったページで「uploading an existing file」を押し、このフォルダの**中身をすべて**ドラッグして入れます（フォルダごとではなく、中のファイルです）。下の「Commit changes」を押します。
4. 上の「Settings」→ 左の「Pages」。「Branch」を **main**、フォルダを **/ (root)** にして「Save」。
5. 数分待つと、同じ画面の上に、公開URLが出ます。`https://あなたのユーザー名.github.io/beatslide/` の形です。これが、アプリのURLです。
6. 手順4でうまくいかない場合は、少し待ってから、ページを更新してください。

※ 別の無料の公開先として、Cloudflare Pages（dash.cloudflare.com → Workers & Pages → Pages → ファイルをアップロード）でも、同じファイルで公開できます。

## 公開前にやること
**書き換えるのは、`config.js` の3か所だけです。** GitHubでは、`config.js` を開いて、鉛筆のマーク（Edit）から編集し、「Commit changes」で保存します。
1. `CONTACT_EMAIL`：プライバシーポリシーに載せる連絡先のメールアドレス（公開されます。専用のアドレスをおすすめします）
2. `POLICY_DATE`：プライバシーポリシーの制定日（例：`'2026-11-01'`）
3. `TIP_URL`：Ko-fiなどの寄付ページのURL（作ってから。入れるまでは、「準備中」と表示されます）

そのあと、公開したURLを、自分のスマホで開いて、動作を確認します。

## スマホで「アプリのように」使う
- **iPhone（Safari）**：公開URLを開く → 共有ボタン → 「ホーム画面に追加」。
- **Android（Chrome）**：公開URLを開く → 右上のメニュー → 「アプリをインストール」または「ホーム画面に追加」。
- ホーム画面から開くと、全画面になり、ネットがなくても動きます。

## 更新するとき
修正したファイルを、GitHubの同じリポジトリに、同じ名前で上書きアップロードします。ネットにつながっていれば、次に開いたときに、新しい版になります。

## バックアップを大事にしてください
写真と設定は、ブラウザの中に保存されています。ブラウザのデータを消したり、長く使わなかったりすると、なくなることがあります（特にiPhoneのSafari）。設定タブの「バックアップ」で、ときどき書き出して、保存してください。

## 確認したこと／していないこと
**確認したこと**（パソコンのブラウザで実行）
- manifestとアイコンが正しく読み込めること、サービスワーカーが動くこと
- ネットを切って再読み込みしても、アプリが開き、写真が残っていること
- バックアップを書き出し、データを消してから読み込むと、写真と音が戻ること
- 5言語の表示に、訳の抜けがないこと

**確認できていないこと**
- 実際のスマホで、ホーム画面に追加したときの見え方と、動き
- iPhoneのSafariで、データが長期間どう保たれるか
- GitHub Pagesでの、実際の公開（私はアカウントを作れないので、あなたの操作が必要です）

## 注意
- フォントを標準以外にすると、Google Fontsに接続します。プライバシーポリシーに書いてあります。
- 広告は、まだ入れていません。入れるときは、プライバシーポリシーの書き換えが必要です。
- 費用、手順、画面の名前は変わることがあります。画面の表示を優先してください。
